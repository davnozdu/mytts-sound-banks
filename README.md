# Звуковые базы MyTTS

Аудио хранится в архивах GitHub Releases, а не в истории Git.

- `open-sounds-events-v1`: 2786 записей событий: BigSoundBank и консервативно отобранные записи Freesound.
- `open-sounds-scenes-v1`: 453 фоновых записи локаций, полная длительность сохраняется.
- `sound-bank-v12`: 869 видов / 2619 файлов вспомогательной сгенерированной базы. Убраны 79 исходных видов / 237 файлов с проверенными заменами.

Каждый архив реальных записей содержит один `LICENSES.md` с авторством, источниками, лицензиями и обработкой. Полный реестр также приложен к релизу. Записи CC BY-NC предназначены для некоммерческого использования; каждая запись сохраняет собственную лицензию.

Отбор основан на проверке метаданных предмета и действия и не гарантирует безошибочное распознавание аудио. Неоднозначные кандидаты исключены из расширения. Приложение пропускает неуверенное совпадение и использует генератор.

События обрезаны до 8 секунд по активности и выровнены по громкости; фоны пережаты без обрезания длины. Манифесты содержат размеры и SHA-256 каждого файла и архива. База скачивается при включении в MyTTS.
